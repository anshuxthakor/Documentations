# Documentations

> A growing collection of documentation — written one page at a time.

This repository contains personal notes, explanations, and practical documentation created while learning and exploring software development.

The goal is simple:

- Understand concepts deeply
- Explain complicated topics clearly
- Keep useful references in one place
- Build a personal knowledge base
- Document the things worth remembering

---

## Documentation Style

These documents are written to go beyond basic definitions.

Each topic focuses on:

- The mental model behind the technology
- Why the concept exists
- How it works internally
- Practical code examples
- Common mistakes and gotchas
- Differences between similar concepts
- Real-world use cases
- Quick revision notes
- Practice questions and activities

The objective is not just to memorize syntax.

> The best documentation explains why something works, not only how to write it.
